# Ретро СССР — интернет-магазин винтажа (WordPress + WooCommerce)

Демо-проект интернет-магазина винтажных и антикварных вещей советской эпохи.
Собирается **автоматически** на WordPress Playground по одному blueprint-файлу.

## 🚀 Быстрый запуск

**Способ 1 (проще всего):** откройте `playground-store.html` → нажмите красную кнопку
«Запустить магазин в Playground» — магазин соберётся автоматически.

**Способ 2:** откройте [playground.wordpress.net](https://playground.wordpress.net) и вставьте
содержимое `playground-link.txt` в адресную строку (blueprint зашит прямо в хеш ссылки).

**Способ 3:** на playground.wordpress.net в нижней панели: **New → Blueprint URL** —
для этого blueprint нужно выложить в интернет (например, на GitHub).

## 🛍 Что входит

| Элемент | Количество |
|---|---|
| Разделы каталога | 12 |
| Товары (по одному в раздел) | 12 |
| Статические страницы | 5 |
| Методы доставки (зона «Россия») | 4 |
| Способы оплаты (демо) | 2 |

### Разделы каталога
Радиоприёмники и магнитофоны · Посуда и хрусталь · Часы · Фото- и кинотехника ·
Виниловые пластинки · Книги, журналы, открытки · Монеты, банкноты, марки ·
Значки и сувениры СССР · Винтажная одежда · Мебель и интерьер ·
Музыкальные инструменты · Игрушки и детские вещи

### Функционал
- WooCommerce: корзина, оформление заказа, личный кабинет
- Валюта — рубли (₽), формат цены `12 500 ₽`
- Атрибуты товаров: **Состояние** (Отличное/Хорошее), **Период** (1960-е…1980-е)
- Доставка: курьер (500 ₽), СДЭК/Почта (350 ₽), самовывоз, бесплатно от 5 000 ₽
- Оплата: картой по счёту (демо), при получении
- Фото-заглушки генерируются автоматически (GD)

## 📁 Структура

```
blueprint.json     — Blueprint: сборка магазина на Playground
setup-store.php    — PHP-скрипт: настройки, каталог, товары, страницы
```

## ⚠️ Важно

Проект **учебный** (для портфолио). Реальные платежи не подключены,
отправка писем отключена. Сайт на Playground живёт в браузере и является
временным — для боевого запуска требуется хостинг с PHP + MySQL.
